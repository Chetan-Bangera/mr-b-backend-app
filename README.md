"# mr-b-backend-app" 

This project reads the Gemini API key from a local `.env` file.

1. Copy `.env.example` to `.env`.
2. Replace `your_gemini_api_key_here` with your actual Gemini API key.
3. Keep `.env` local and never commit it to Git.

The repository keeps `.env` ignored and ships a safe `.env.example` template."
